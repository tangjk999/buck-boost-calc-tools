# 双向 Buck-Boost 计算工具

基于《双向 Buck-Boost 完整计算：从参数到选型》文档设计的在线计算工具。

## 功能

- **占空比计算**: Buck/Boost双模式占空比计算
- **电感计算**: Buck/Boost最小电感值计算，并预留10%~20%裕量
- **电流计算**: 平均电流、纹波电流、峰值电流计算
- **开关管选型**: 电流应力分析与额定电流计算
- **电容计算**: 输出滤波电容计算
- **环路稳定性**: 穿越频率计算

## 使用方法

直接在浏览器中打开 `index.html` 文件即可使用。

## 计算参数

| 参数 | 说明 | 推荐范围 |
|------|------|----------|
| V_H | 高压侧电压 | 200~400V |
| V_L | 低压侧电压 | 12V、48V |
| P_o | 额定输出功率 | - |
| f_sw | 开关频率 | 50kHz~200kHz |
| k | 纹波电流比例 | 0.2~0.4 (推荐0.3) |

## 计算公式

### 占空比
- Buck: D_buck = V_L / V_H
- Boost: D_boost = 1 - V_L / V_H

### 电感
- L_buck = V_L × (V_H - V_L) / (V_H × f_sw × ΔI_L)
- L_boost = V_L × (V_H - V_L) / (V_H² × f_sw × ΔI_L)

### 电流
- I_L_peak = I_L_avg + ΔI_L / 2
- I_sat ≥ 1.2 × I_L_peak
